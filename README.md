# Minutrove

Turn focused effort into time and budget for activities you value.

Minutrove is a personal quest-and-award app planned for iOS and Android. It is currently in product design; this repository does not yet contain a runnable app.

## Product direction

- Create configurable **Quests** that earn **Coins** and **Gems** through active session time.
- Redeem **Awards** that grant time, a spending budget, or both.
- Keep partial earnings and unused award allowances.
- Organize items into groups and review activity through daily, weekly, monthly, and yearly graphs.
- Choose each item's **type**, **icon**, and **color** independently. Any icon may be reused for any quest or award.
- Run one quest or timed award at a time.

## Repository scope

This single repository will hold the mobile product for both platforms: application code, shared domain logic, platform integrations, original assets, tests, and build configuration.

The repository boundary does not choose a framework. A shared mobile framework or separate native clients can both live here. The source layout and build instructions will be established when the implementation approach is agreed.

App distribution is deferred while the product requirements and interface are developed.
